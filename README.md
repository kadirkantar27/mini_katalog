# Mini Katalog Uygulaması

Bu proje, Flutter temel bileşenleri ve Navigator kullanımı ile geliştirilmiş, API'den (lokal JSON üzerinden) veri okuyarak ürünleri listeleyen basit bir katalog uygulamasıdır.

## 🚀 Kullanılan Teknolojiler ve Sürüm
* **Flutter Sürümü:** 3.13+ (veya üzeri)
* **Paketler:** Sadece temel `material.dart` kullanılmıştır. Ekstra paket içermez.
* **Mimari:** Route Arguments ile sayfa arası veri taşıma, GridView, temel state yönetimi (setState).

## 🛠️ Çalıştırma Adımları
1. Bu depoyu bilgisayarınıza indirin (Clone).
2. Terminali açın ve proje dizininde `flutter pub get` komutunu çalıştırarak bağımlılıkları güncelleyin.
3. Uygulamayı bir emülatörde, fiziksel cihazda veya tarayıcıda çalıştırmak için `flutter run` komutunu kullanın. (Tarayıcıda görsellerin yüklenmesi için CORS kısıtlamaları kapalı başlatılması gerekebilir).
